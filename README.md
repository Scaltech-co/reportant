The built production file is located in:
dist/app.js

Build tools used:
npm and a JavaScript bundler.

Steps to generate the production file:

1. Clone the repository
git clone https://github.com/Scaltech-co/reportant.git

3. Install dependencies
npm install

4. Build the production assets
npm run build

After running the build command, the generated file will be created at:
dist/app.js
